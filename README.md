### DESCRIPTION
A-maze-ing is a project which goal is to learn how to generate mazes, solve them, and display them using
MLX, an extern grapical module.

### INSTRUCTIONS

To **_install_** the project virtual environment :

```bash
make install
```

To **_run_** the program :

```bash
make run
```

To build the **_mazegen_** package :

```bash
make wheel
```

To **_clean_** the files generated by the installation :

```bash
make clean
```

To check flake8 and mypy **_norms_** :

```bash
make lint
```

To check flake8 and mypy **_norms_** with **_strict_** flags :

```bash
make lint-strict
```

To run the program with the **_python debugger_** :

```bash
make lint
```

### STRUCTURE

The program uses a standalone wheel package called **_mazegen_**. Its code is
in the **_mazegen_** directory. This part of the program is in a package in order
to be reusable by other students as a **_maze generator_** in the pacman project.
To see how to use it, you can refer to the README of the package.

The entry point of the program, called **_a_maze_ing_**, is located at the root of the
project. The remaining sources are in a directory called **_srcs_** that has three files:
*colors.py* to handle colors, *engine.py* to handle display and *loader.py* to handle the
parsing. 

The parsing loads a file named **_config.txt_** which has key-value paired informations
for the maze to create, solve and display. They are : SEED, WIDTH, HEIGHT, ENTRY, EXIT, 
OUTPUT_FILE, and PERFECT. Here is an example:
```
# config file
WIDTH=25
HEIGHT=20
ENTRY=0,0
EXIT=24,19
OUTPUT_FILE=maze.txt
PERFECT=False
SEED=42
```
As you can see, lines starting by *__#__* are ignored by the parser.
